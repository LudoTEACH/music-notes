# Lire les notes sur la portée (clé de sol)

Application web statique (un seul fichier `index.html`) : découverte, notes isolées avec son, mélodies par intervalles.

## Mise en ligne avec GitHub Pages
1. Créer un nouveau dépôt (ex. `note-reading`), puis **Add file > Upload files** et déposer `index.html` et `README.md`.
2. **Settings > Pages > Source : Deploy from a branch**, branche `main`, dossier `/ (root)`, **Save**.
3. Le lien apparaît en haut de la page Pages après 1 à 2 minutes.
